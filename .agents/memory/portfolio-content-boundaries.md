name: Portfolio content boundaries
description: User-stated content constraints for the personal data science portfolio.
---

Keep the portfolio focused on technical projects, technical skills, public professional profiles, achievements, and certificates. Do not include contact details, education, employment history, or soft skills.

**Why:** The user wants employers to assess technical work without unrelated personal information.

**How to apply:** Preserve these exclusions in future edits to the portfolio; use only the requested public GitHub and LinkedIn links for profiles.
